# Contributing

NerdSSHell is source-visible for transparency, review and learning, but the project is not currently accepting unsolicited code contributions.

For bugs or feature requests, open a GitHub issue with the NerdSSHell version, Windows version, a redacted reproduction and the expected behavior. Use fake hosts and synthetic terminal content. Remove credentials, tokens, usernames, private paths and terminal output before sharing.

Please do not open pull requests unless the maintainer has specifically asked you to work on a change. Unsolicited pull requests may be closed without review. Security vulnerabilities follow [SECURITY.md](SECURITY.md) and must not be disclosed in a public issue.
