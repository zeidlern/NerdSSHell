# Getting help

Start with the [NerdSSHell manual](https://github.com/zeidlern/NerdSSHell/wiki) and [troubleshooting guide](docs/wiki/Troubleshooting.md). Download official Windows assets from [Releases](https://github.com/zeidlern/NerdSSHell/releases); check the notes for the exact version and signing status.

For a bug, use the [bug report form](https://github.com/zeidlern/NerdSSHell/issues/new?template=bug_report.yml). For an enhancement, use the [feature request form](https://github.com/zeidlern/NerdSSHell/issues/new?template=feature_request.yml). Other usage questions can be posted in [Issues](https://github.com/zeidlern/NerdSSHell/issues).

Include the app and Windows versions, session type, minimal reproduction, and expected versus actual behavior. Screenshots and short logs help when they are sanitized. Use fake hosts and synthetic terminal content; remove passwords, keys, tokens, private paths, usernames and connection profiles before posting. The output-sharing preview lets you edit text before copying, but does not automatically redact secrets.

Security vulnerabilities belong in the [private reporting route](SECURITY.md). Community support is provided as time permits; no response-time guarantee is offered.
