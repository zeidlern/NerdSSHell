# Development history

The original source was delivered as a ZIP after a connector upload failed. It was subsequently imported into GitHub, tested and completed locally. Those original delivery limitations are historical, not the current repository state.

Current evidence is summarized in ACCEPTANCE-RESULTS.md. The subsequent security review and tested hardening are documented in SECURITY-REVIEW.md. PUBLIC-RELEASE.md tracks what must be verified before publishing source/history or a signed release.

Do not treat historical test counts, old source hashes, or an unsigned installer as proof of current security or publisher identity.
