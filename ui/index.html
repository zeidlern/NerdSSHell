Copy & Paste


PuTTY-style: copy on mouse release; double-click selects a word. The highlight stays visible. Clipboard history or sync may retain copied text.


Ctrl+C
Copy the selection. With no selection, send an interrupt.
Ctrl+V
Paste into the focused terminal. Multiline commands require confirmation.
Right-click
Copy selected terminal text, or paste when nothing is selected.






Terminal Colors



Presets replace terminal colors only, including advanced colors. Your window colors and copy setting stay unchanged.


These are palette colors, not universal syntax settings. Your editor or command-line program chooses which color means a keyword, string or comment. Programs that send exact RGB colors bypass this palette.

Configure Actions
Actions are commands for a terminal’s operating system and shell. Choosing one in a session inserts its command and sends Enter in that session.




Actions
Action editor
Select a recipe or create a custom action. Nothing executes here.






Configure Favorites
Choose the actions that appear as favorites in matching terminal sessions. Selecting a favorite inserts its command and sends Enter in that session.










Notifications & Alerts
Looks for an interactive prompt at the terminal’s cursor. Ordinary inactivity and a normal shell prompt do not request attention.




One prompt produces one alert. Answering it or resumed output clears its waiting state. Notifications identify the session without including terminal output.






Sessions & History
Defaults for new saved connections. Existing connections keep their individual settings; edit a connection to change them.





Recording is optional and unencrypted. Output can contain secrets. It captures output received while views are open and does not record server activity while disconnected.


Persistent Session (tmux) is chosen when creating a remote session. PowerShell and Command Prompt are local, nonpersistent shells.










Recorded output
Local text archive, not a screen replay. Search covers the newest 128 MiB and shows up to 300 matching lines. Export includes the full retained archive. Only received output is recorded; server-side retained history may cover a disconnection.
